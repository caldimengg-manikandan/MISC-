# CALMISC — Application Overview

## What is CALMISC?
CALMISC is a web-based steel estimation platform for miscellaneous metal fabrication. It helps estimators and project managers at steel fabrication companies to:
- create and manage project estimations
- calculate steel weights, labor hours, and total costs
- track project workflow status
- export BOM (Bill of Materials) and cost summaries to Excel and PDF

## Main Sections of the App

### 1. Dashboard
- Overview of all company projects
- Metrics: total projects, steel weight, estimated costs
- Quick filters by status (New, In Progress, Review, Submitted)
- Recent activity feed

### 2. Projects (Estimations List)
- Paginated list of all projects in your company
- Search by project name, number, or customer
- Filter by status, engineer, or date range
- Click any project to open its detail page

### 3. Project Detail (Project Info)
- Set project name, number, customer, location
- Assign engineer
- Set submission deadline and AISC certification status
- View estimation summary (total steel weight, total cost)
- Click "Go to Estimation Module" to enter the calculation interface

### 4. Estimation Module — Stair & Railings
- Add multiple stair flights and rail configurations
- Each item has its own input form and live calculation preview
- After configuring all items, click "Run Estimation" for the full summary
- Rates bar shows current steel, shop, and field rates in use

### 5. Reports
- View and print full project reports
- Export BOM to Excel spreadsheet
- Print PDF estimate reports

### 6. Settings
- **Pricing Settings**: Set global steel price, labor rates, scrap factor, tax
- **Customer Master**: Manage customer company records
- **System Admin**: User management, company configuration (admin only)
- **Personalization**: Theme, display preferences

## Navigation
- Left sidebar: main navigation
- Projects with active estimations show in the sidebar project list
- Global save button in the header saves the current page's data
- "New Estimation" button creates a blank project

## Key Concepts
- **Project**: A single estimation job for a customer
- **Stair Flight**: One staircase with its own risers, stringers, pans/grating
- **Rail Run**: One continuous rail section (wall rail, guard rail, etc.)
- **Platform**: A horizontal steel landing or mezzanine
- **Calculation Summary**: The final breakdown of all costs per project
