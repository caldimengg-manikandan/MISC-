# Report Guide — Exporting Estimates from MISC Pro

## Available Export Formats

### 1. BOM Excel Export
Exports a full Bill of Materials spreadsheet with detailed line items.
**How to export:**
- Open a project in the Estimation Module (Stair & Railings or Railings)
- Click the "Excel BOM" button in the header actions bar
- The file downloads automatically as an .xlsx file

**Contents of BOM Excel:**
- Project header: name, number, customer, date
- Rate table: steel price, labor rates, scrap factor, tax rate
- Stair flights: each stair listed with steel lbs, shop hrs, field hrs, costs
- Rail sections: each rail listed with LF, post qty, steel weight, costs
- Platform sections: dimensions, area, costs
- Grand total summary at the bottom

### 2. PDF Estimate Report
Prints a formatted estimate report for client submission.
**How to export:**
- Use the Export menu in the main header (printer icon)
- Select "Print PDF" option
- A print-ready window opens in a new browser tab
- Use your browser's Print (Ctrl+P) function to save as PDF or print

**Contents of PDF:**
- Company branding header
- Project details table (name, number, customer, deadline)
- Rates used section
- Itemized stair flights table
- Itemized rail sections table
- Grand total with tax breakdown

### 3. Live Data Report (Admin)
Available from the Reports section in the main navigation.
- Shows aggregated data across all projects
- Filter by status, date range, or engineer
- Export to Excel

## Tips for Reporting
- Make sure to run the full estimation (click "Run Estimation") before exporting
- The BOM will show $0 values if no estimation has been calculated
- Project details (customer, deadline) can be edited before export without re-running the estimate
- If the export shows an error "project not saved", save the project first from the Project Detail page
